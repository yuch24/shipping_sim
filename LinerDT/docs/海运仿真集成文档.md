# 海运仿真集成文档

## 项目概述

### 背景
本项目将已完成的"海运仿真"Python后端系统迁移并集成到"LinerDT"前端可视化平台，实现完整的海运航运仿真可视化系统。

### 核心目标
- 将DEVS仿真引擎集成到LinerDT平台
- 提供海运仿真的可视化界面
- 实现船舶航行动画、港口拥堵、油耗收益等指标的实时展示
- 支持参数配置和实时控制 

### 技术方案
**方案A：迁移到LinerDT**
- 海运仿真作为Python包安装
- 完全替换scheduler.py，使用DEVS引擎作为唯一仿真引擎
- 数据文件迁移到LinerDT backend/app/data/
- 分阶段开发（先核心，后完善）

#### fuel_service.py (163行)
**IMO油耗计算公式**：
```
F = P × SFOC × LoadFactor × Time
```
- P: 主机功率 (kW)
- SFOC: 特定燃油消耗率 (g/kWh)
- LoadFactor: 负载因子 (0.7-1.0)

**核心方法**：
- `create_calculator(vessel_name, route_id, capacity)`
- `calculate_fuel(vessel_name, speed, distance, load_factor)`
- `calculate_cost(vessel_name, fuel_tons)`

#### revenue_service.py (182行)
**收益成本分析**：
```
总收入 = Σ(TEU × 运费率)
总成本 = 燃油成本 + 港口成本 + 时间成本
净利润 = 总收入 - 总成本
利润率 = 净利润 / 总收入
```

**关键修复**：
- `VesselCharacteristics` 添加必需参数：
  - `design_speed=DEFAULT_SPEED`
  - `main_engine_power=DEFAULT_MAIN_ENGINE_POWER`
  - `sfoc=DEFAULT_SFOC`

#### congestion_service.py (141行)
**M/M/c排队模型**：
- λ: 到达率 (船舶/天)
- μ: 服务率 (船舶/天/泊位)
- c: 泊位数

**指标计算**：
- 队列长度 Lq
- 平均等待时间 Wq
- 泊位利用率 ρ

## 技术细节

### DEVS仿真引擎

**仿真循环**：
```python
engine.initialize()
while engine.step():
    # 收集输出
    events = engine.events      # 船舶事件
    stats = engine.stats        # 港口统计
    cargo = engine.cargo        # 货物批次
    
    # 推送数据
    visualization_sync.push_state(state)
    
engine.finalize()
```

**数据类型**：
- `VesselEvent` - 船舶到港/离港事件
- `PortStats` - 港口吞吐统计
- `CargoBatch` - 货物批次数据

### Agent框架

**树形结构**：
```
Engine
  └─ Model
      ├─ Ships (AgentPopulation)
      │   ├─ AEU-W1
      │   ├─ AEU-W2
      │   └─ AEU-W3
      └─ Ports (AgentPopulation)
          ├─ CNSHA
          ├─ NLRTM
          └─ SGSIN
```

**Agent创建修复**：
```python
# 错误方式
agent = Agent(name="AEU-W1", owner=model_agent)
agent.set_parameter("speed", 19.0)

# 正确方式
agent = Agent(owner=model_agent)
agent._name = "AEU-W1"
agent.set_param("speed", 19.0)
```

**问题**：
```python

    vessel_name=vessel_name,
    route_id=route_id,
    design_speed=DEFAULT_SPEED,
    main_engine_power=DEFAULT_MAIN_ENGINE_POWER,
    sfoc=DEFAULT_SFOC,
    capacity_teus=capacity
)
```

**待解决**：
